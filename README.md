# Garment Factory Attendance Management System

A Laravel application for attendance and workforce administration at one garment factory, with separate HR Admin, Supervisor, and Employee access.

## Local development

1. Configure the root `.env` for the intended development database. Never commit this file.
2. Apply the reviewed migrations to that development database before creating accounts.
3. Install frontend dependencies with `npm install`, then start Vite with `npm run dev`.
4. Start Laravel with `php artisan serve` and open `http://127.0.0.1:8000`.

Run the automated tests with:

```powershell
php artisan test
```

The test configuration uses SQLite in memory.

## First HR Admin account

After the `users` table and role migration have been applied to the intended database, run:

```powershell
php artisan app:create-first-admin
```

The command securely prompts for the administrator's name, email, and password. Password input is hidden, must be confirmed, and must contain at least 12 characters. The command refuses to create another HR Admin if one already exists. There is no public registration route, and this command does not run migrations.

Never place account credentials in source code, seeders, or version control.

## Current phase

Phase 1 provides login, logout, role-protected dashboards, and initial HR Admin account creation. Employee administration, team assignments, attendance recording, leave, overtime, and reports are not implemented yet.

## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.
